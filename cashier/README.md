# كاشير برو

Python 3.8 (32-bit) + Tkinter + SQLite. مفيش مكتبات تقيلة، والـ EXE الناتج 32-bit فبيشتغل على ويندوز 7/8/10/11 بنسختيه.

## الحصول على ملف EXE
1. **على جهاز ويندوز:** ثبّت Python 3.8.10 (32-bit) ثم شغّل `build.bat` ← `dist\CashierPro.exe` (ملف واحد).
2. **من غير ما تثبت حاجة:** ارفع المجلد على GitHub ← تبويب Actions ← build-exe. هتلاقي `CashierPro.exe` و `CashierPro-Setup.exe` في الـ Artifacts.

## أول تشغيل
شاشة تسجيل أول حساب (مدير) بإيميل أو موبايل + كلمة سر. بعدها أي مستخدم/كاشير يتضاف من (المستخدمين).
البيانات في `%APPDATA%\CashierPro\cashier.db`، ونسخة احتياطية تلقائية يومياً في `Documents\CashierPro_Backups`.

## استعادة كلمة السر (OTP)
من الإعدادات ← الإرسال:
- **Gmail:** فعّل التحقق بخطوتين وأنشئ App Password (16 حرف).
- **SMS:** حساب Twilio (SID + Token + رقم).
- **WhatsApp:** WhatsApp Cloud API (Token + Phone Number ID + قالب OTP معتمد من Meta).
اضبطها وجرّبها بزر "تجربة" قبل ما تحتاجها. لو نسي المدير الوحيد كلمة السر وقنوات الإرسال مش مظبوطة مفيش استرجاع.

## الطابعة والباركود
- سكانر USB: بيشتغل زي الكيبورد، والمؤشر دايماً في خانة الباركود (F2). ممكن تكتب `3*باركود` للكمية.
- سكانر سيريال: حط رقم COM في الإعدادات ← الباركود.
- الطابعة: "طابعة ويندوز" هي الأضمن للعربي. باقي الأنواع ESC/POS (شبكة / COM / خام) محتاجة ضبط رقم Code Page حسب موديل الطابعة.
